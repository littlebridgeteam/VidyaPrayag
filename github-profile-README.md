### Currently Building

</div>

<br>

**[Quantum Insights](https://quantuminsights-seven.vercel.app/)** — multi-agent AI analytics platform. **Live.**

15+ autonomous agents, 7 LLM providers with circuit breakers and auto-failover, a visual dashboard editor with 24+ chart types, and a financial intelligence layer. Built on FastAPI, React 19, PostgreSQL, Redis. Runs on $0/month infrastructure.

`FastAPI` `React 19` `TypeScript` `PostgreSQL` `Redis` `Plotly.js`

<br>

**[Enroll+ (VidyaPrayag)](https://enrollplus.vercel.app/)** — AI-powered school management platform. **Live.**

One Kotlin Multiplatform codebase shipping to Android, iOS, Web, Desktop, and Server. Admin, Teacher, and Parent portals. 18 scheduled jobs, 6 LLM providers, WhatsApp Cloud API, offline-first sync. Built solo.

`Kotlin Multiplatform` `Compose` `Ktor` `Supabase` `Firebase`

<br>

**[FORGE-X v4 — Financial RAG](https://github.com/hereugo-ak/financial-rag)** — quantitative prediction engine.

Trained on financial data since 2000. 73.6% achieved accuracy. Stacked ensemble of 6 base models producing 51 meta-features, with regime detection, meta-labelling, and calibrated uncertainty. Not a trading bot. A defensible intelligence layer.

`Python` `scikit-learn` `PyTorch` `FastAPI` `HuggingFace Spaces`

<br>

**Telegram Job Bot** — autonomous job application engine. *Coming soon.*

Multi-agent system that scrapes major job platforms, scores listings against a CV using embedding similarity, and auto-applies via headless browser automation with fingerprint randomization and proxy rotation.

`Python` `Playwright` `LangChain` `Telegram API`
