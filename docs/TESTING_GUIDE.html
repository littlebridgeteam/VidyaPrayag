Phase 1: School Admin — Create School & Onboarding

SCHOOL ADMIN PORTAL

1.1 Sign Up as School Admin

1. Open the Enroll+ app → tap Sign Up.
2. Enter an email address (e.g. admin@vidyaprayag.edu.in) and password.
3. Select role: School Admin.
4. Complete signup — you'll be logged in and redirected to onboarding.

1.2 Onboarding Wizard (4 Steps)

The onboarding wizard has 4 steps: BASIC → BRANDING → ACADEMIC → REVIEW.

StepFieldsWhat to Enter
BASIC School name, board, medium, gender type, contact phone, contact email, principal name, address, city, district, state, pincode Enter realistic values, e.g. "Vidya Prayag School", CBSE, English, Co-Ed, etc.
BRANDING Logo URL, brand color, cover image URL Upload a logo or use a placeholder URL. Pick a brand color (e.g. navy blue).
ACADEMIC Classes & sections Add classes: Nursery, LKG, UKG, 1-10. Add sections A, B, C for each class.
REVIEW Review all entered data Verify all details. Submit to complete onboarding. School is now active.

1.3 Verify School Created

After onboarding, go to Settings → School Profile. Verify:
  • School name, address, board appear correctly
  • Logo and brand color are applied
  • Classes & sections listed match what was entered

Phase 4: Parent — Create Account & Link Child

PARENT PORTAL

4.1 Create Parent Account

1. Open the Enroll+ app → tap Sign Up.
2. Enter one of the test phone numbers (e.g. +919535248581).
3. Tap Send OTP. The server will generate OTP 123456 for this number.
4. Enter OTP: 123456.
5. Enter name (e.g. "Rajesh Sharma") and select role: Parent.
6. Complete signup. You'll be logged in as a parent.

4.2 Link Child to School

1. After login, go to Link Child (or it may prompt automatically).
2. Step 1 — Select School: Search for "Vidya Prayag School" and select it.
3. Step 2 — Enter Child Details:
  • Child name (must match the student's name in the school records)
  • Class (e.g. 6)
  • Section (e.g. A)
  • Roll number (e.g. 001)
4. Step 3 — Submit Link Request: A pending link request is created. The school admin must approve it (see Phase 5).
5. Repeat for all three test parent numbers, linking different children.

Phase 5: School Admin — Approve Child Link Requests

SCHOOL ADMIN PORTAL

5.1 View Pending Link Requests

1. Log in as school admin.
2. Go to People → Link Requests (or People → Students → Link Requests tab).
3. You should see pending requests from the parents who submitted in Phase 4.

5.2 Approve / Reject Link Requests

1. Review each pending request — verify child name, class, roll number match a student in the school.
2. Tap Approve for correct matches.
3. Tap Reject for incorrect matches (with a reason).
4. The parent receives a notification on approval/rejection.

Copy and paste this prompt into Claude/ChatGPT:

Generate a CSV file for bulk student import into a school management system.
The CSV must have these columns (exact header):
full_name,class_name,roll_number,section,student_code,parent_phone

Requirements:
- Generate exactly 120 students
- Classes: 6, 7, 8 (40 students each)
- Sections: A, B, C for each class (distribute roughly equally, ~13-14 per section)
- Roll numbers: Start from 001 in each class+section (e.g. 6-A has 001-014, 6-B has 001-013, etc.)
- Student codes: Auto-generate as VP2026XXXX (sequential, starting VP20260001)
- Names: Use realistic Indian student names (mix of North and South Indian names, both male and female)
- Parent phones: 
  - For 5 students in Class 6-A, use these exact parent phone numbers:
    +919535248581
    +91XXXXXXXXX (replace with test number 2)
    +91YYYYYYYYY (replace with test number 3)
    +919535248581 (reuse for a second child)
    +91XXXXXXXXX (reuse for a second child)
  - For all other students, leave parent_phone blank
- Output ONLY the CSV content, no explanation

Example format:
full_name,class_name,roll_number,section,student_code,parent_phone
Aarav Sharma,6,001,A,VP20260001,+919535248581
Diya Patel,6,002,A,VP20260002,
Vivaan Reddy,6,001,B,VP20260015,
...
